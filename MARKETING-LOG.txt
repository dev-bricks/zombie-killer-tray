- Core Positioning: Conservative Windows system tray utility for cleaning up orphaned Model Context Protocol (MCP) servers and language server processes without blanket process-tree kills.

2. TARGET PERSONAS & USER JOURNEYS
================================================================================
1. [PERSONA-01] AI Engineers & Multi-Agent Developers (Claude Code, Codex CLI, Gemini Antigravity, Kimi)
   - Needs: Run multi-agent orchestrations and MCP servers locally on Windows without accumulating dozens of orphaned background processes that consume RAM and hold file locks.
   - Pain Points: When agent sessions exit abruptly, MCP server subprocesses (node.exe, python.exe) remain running as zombies in the background.
   - Solution: Conservative background detection and termination of dead-parent MCP processes with zero risk to active editors or shells.

2. [PERSONA-02] DevOps & System Reliability Engineers (SREs)
   - Needs: Reliable, auditable process supervision on developer workstations and CI runners.
   - Pain Points: Blanket taskkill /F /T scripts frequently terminate unrelated background services, terminal sessions, or active developer tools.
   - Solution: Pinned Win32 handle architecture, two-sample verification, pre-termination audit records, and strict allowlists.

3. [PERSONA-03] Windows Developers using Language Servers (rust-analyzer, clangd, gopls, pylsp)
   - Needs: Clean development environment where language server background processes cleanly terminate when their parent IDE or editor closes.
   - Pain Points: Lingering language servers continue holding file locks on source trees and build outputs.
   - Solution: Allowlisted orphan reaping that only touches verified language servers whose parent editor is dead and whose CPU usage is zero.

4. [PERSONA-04] Enterprise Security & Compliance Auditors
   - Needs: Guarantee zero-egress, local-first operation, unprivileged verification options, and complete license transparency.
   - Pain Points: Unknown background utilities that phone home or require constant unverified administrative access.
   - Solution: 100% Local-First / Zero-Egress (INV-LOCAL-01), unprivileged --check mode (RunAsInvoker / INV-SEC-02), Level 1 SBOM in THIRD_PARTY_LICENSES.md, and codified 48-hour security response SLA (INV-SLA-10).
